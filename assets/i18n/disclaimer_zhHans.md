# 巴士预报-MBKa 免责声明

## 1. 数据来源

- 路线、车站位置及路线走向来自澳门特区政府开放数据平台（data.gov.mo）。
- 班次及首末班车时间整理自交通事务局（DSAT）公布的路线时间表，整理过程中或有错漏。
- 实时到站、道路车速及改道、封站通告参考 DSAT 提供的数据。

所有数据的权利归其原权利人所有。

## 2. 到站时间属于推算

到站时间是根据巴士实时位置、道路车速、路线距离及过往行车记录推算出来的估计，并非巴士公司承诺的班次。交通拥堵、上下客时间、改道或数据延迟等因素，都可能使实际到站时间有所不同。

## 3. 路线规划仅供参考

路线规划及换乘建议按现有数据自动计算，未必是最快或最合适的方案，也未必反映临时改道、封路或特别交通安排。出行前请预留足够时间。

## 4. 通告及临时安排

改道、临时封站及特别班次等信息可能未能即时或完整显示，一切以 DSAT 及巴士公司的官方公告和现场安排为准。

## 5. 服务可用性

本应用程序可能因系统维护、网络问题或数据来源中断，暂时无法提供部分或全部数据，恕不另行通知。

实时到站及道路车速数据可能随时暂停提供，届时只会显示时间表班次。
